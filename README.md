# Sistema de Inscrições

Sistema para gerenciamento de inscrições com validações, regras de capacidade e automações.

## Status
**Protótipo / em desenvolvimento.**

## Objetivo
Criar um fluxo de inscrição mais controlado, com validação dos dados e encerramento automático ao atingir a capacidade definida.

## Funcionalidades
- Formulário de inscrição
- Campos obrigatórios e validações
- Opções personalizadas de cadastro
- Controle de limite de participantes
- Mensagem automática ao atingir a lotação
- Organização das respostas

## Integrações
- Google Forms
- Google Apps Script
- Google Sheets

## Privacidade
Dados de participantes e outras informações pessoais não devem ser publicados no repositório.
